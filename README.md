# A Benchmark Dataset of Lytic Polysaccharide Monooxygenase and non-LPMO Sequences for Classification
Lytic Polysaccharide Monooxygenases (LPMOs) are copper-dependent enzymes that catalyze the oxidative cleavage of crystalline polysaccharides such as cellulose and chitin. We present a rigorously curated dataset of LPMO and non-LPMO protein sequences to support the development and benchmarking of computational enzyme classification tools. The dataset encompasses eight LPMO families (AA9, AA10, AA11, AA13, AA14, AA15, AA16, AA17) and nine non-LPMO families (AA1, AA2, AA3, AA4, AA5, AA6, AA7, AA8, AA12), each annotated with Enzyme Commission numbers to facilitate downstream functional analysis. Sequence identifiers were sourced from the CAZy database, and corresponding sequences were extracted from GenBank and the Joint Genome Institute using automated batch accession retrieval and organism-specific downloads. Comprehensive preprocessing included the removal of redundant entries, exclusion of sequences with ambiguous residues, and filtering of partial sequences. Redundancy was further minimized using CD-HIT at a 70% sequence identity threshold, resulting in a balanced, high-quality dataset suitable for machine learning model training, functional annotation, and high-throughput enzyme classification.
